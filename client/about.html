How WC3V Works

1

Upload a .w3g replay

The same binary replay file Warcraft III saves after every game. Drag and drop or click to upload.

2

Parser reconstructs the game

Player actions are extracted (building placements, unit training, hero skills, upgrades, resource events) and the full game state is reconstructed.

3

Visual breakdown renders

Supply-indexed build order timeline, tier snapshots, and live minimap with unit positions. Scrub, pause, and study any moment.

Open Source

WC3V is free, open-source software licensed under GPLv3. Full source on GitHub. Built with Node.js, D3.js, and plain HTML/CSS/JS. No frameworks, no build tools, no accounts.
