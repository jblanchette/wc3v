Warcraft III Community Resources

A hand-picked list of trusted Warcraft III sites, ladders, and open-source tools. WC3V is not affiliated with any of these projects — we just think they're great and want more people to find them.

Major Community Sites

The places we visit ourselves for news, ladder play, builds, and discussion.

Liquipedia (Warcraft)

The community wiki: tournaments, patch notes, player profiles, hero and unit data, build orders, and stats. The first place to look for almost anything WC3.

Visit Liquipedia →

W3Champions

The community-run matchmaking ladder and client used by virtually all active competitive players. Free to install and play, with active seasons and league rankings.

Visit W3Champions →

Back2Warcraft

The foremost English-language broadcast brand for Warcraft III. Tournament casts, weekly news, articles, and a deep YouTube archive of pro games.

Visit Back2Warcraft →

Hive Workshop

Long-running modding community: custom maps, models, icons, tutorials, and tools. The home of WC3 mapmaking for over twenty years.

Visit Hive Workshop →

Warcraft3.info

Independent news site covering tournaments, patches, and competitive play. A solid alternative source for English-language WC3 reporting.

Visit Warcraft3.info →

Warcraft 3 Gym

Training and coaching resource for ladder players. Build orders, drills, and structured improvement paths for all four races.

Visit Warcraft 3 Gym →

Reddit — r/WC3

Community discussion, replay shares, news threads, and questions. A good place to feel the pulse of the broader player base.

Visit r/WC3 →

Tools That Power This Project

WC3V wouldn't exist without these open-source projects. If you're building anything in the WC3 space, start here.

w3gjs

The Node.js .w3g replay parser by PBug90. WC3V's entire server-side parsing pipeline is built on top of it.

View on GitHub →

HiveWE

Open-source Warcraft III world editor by stijnherfst. We use it as a reference for terrain rendering and map data formats.

View on GitHub →

war3-model

MDX/MDL model parser by 4eb0da. Useful for anyone working with WC3's 3D model format.

View on GitHub →

StormJS

JavaScript port of StormLib by wowserhq. Reads MPQ archives — the file format WC3 uses for maps and assets.

View on GitHub →

D3.js

The data-visualization library powering WC3V's scrubber math, scales, and timeline geometry.

Visit D3 →

node-canvas

Server-side Canvas API by Automattic. Used to render minimap images during replay processing.

View on GitHub →

Other libraries we lean on: pngjs, rbush, image-js, image-size, pako, and fflate.
