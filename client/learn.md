# WC3V Build Finder

Pick a race, a hero and the kind of army you like playing, and get one build to learn rather than a list to choose from.

The Build Finder is for players who are new to Warcraft III or new to a race. It narrows the library down to a single build that fits how you already want to play, explains what it is trying to do, and links the pro replay so you can watch it run at full speed before you try it yourself.

One build, learned properly, beats five builds half-remembered. Come back and switch when the first one stops losing you games.

Every build the finder can land on is listed at https://wc3v.com/builds, with its strategy, tier progression, common mistakes and the tournament games behind it.
