One-time setup. Four short steps, and every choice stays in Settings.

Stays on your machine

WC3V reads the replay files Warcraft III already writes. Nothing else.

  • Your replays never leave this PC. No upload, no cloud.
  • No account, no login, no paywall. Free and open source.
  • No game injection, no memory reading. It cannot see a game in progress.
  • Nothing dials out unless you switch it on.

Two exceptions, both with a switch in Settings: an anonymous usage count (app started, game parsed, version number, nothing about you), and W3Champions lookups if you turn them on in step 3.
